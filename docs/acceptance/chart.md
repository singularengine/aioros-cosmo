# Chart

shadcn/ui's `chart` (Recharts in a `ChartContainer`, with `ChartTooltipContent` and `ChartLegendContent`) as
Aioros.Pictor's charts in the `Aioros.Cosmo.Charts` package: each color theme gives Pictor's theme keys from the chart
tokens and `ChartContainer`'s overrides; `c:ChartTooltipContent` is a tooltip's `ContentTemplate` (dot, line and dashed
indicators, `HideLabel`, `HideIndicator`, a line per series); `c:ChartLegendContent` and `c:ChartLegendItem` are a
legend's `Template` and `ContentTemplate`; `c:CosmoChartsTheme` sets the charts' font and the `chart-toggles` list box of
the interactive examples; `c:ChartConfig` is shadcn/ui's `ChartConfig`, and Pictor's converters its formatter functions.
shadcn/ui pins Recharts 3.8.0, whose behavior Pictor follows where shadcn/ui's examples show it (Pictor's decision
"Recharts 3 where it differs"; Cosmo's decisions "Charts: Recharts 3.8.0 against 2.15.4" and "Recharts 3.8.0, measured").
