# Trace

shadcn/ui's `trace` from the radix base (`apps/v4/registry/bases/radix/ui/trace.tsx`) in the radix-rhea style, on Cosmo's
new-york-v4 tokens (decided with the user on 2026-10-19): an agent's steps as 14 px muted lines 8 px apart, each a 16 px
icon, a title cut short with an ellipsis and a description at 70% of `--muted-foreground`; a line is `--destructive` in
error, at 60% opacity while pending; a collapsible step opens below its trigger, behind a 1 px left border, its chevron
turned a quarter. Cosmo's `c:Trace` (a `StackPanel`), `c:TraceLine` (a `ContentControl`: `Icon`, `Description`,
`Trailing`, `Status` as the `:running`, `:error` and `:pending` pseudo-classes) and Avalonia's `Expander` with the `trace`
class.
