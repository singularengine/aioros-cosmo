# Badge

shadcn/ui's `badge` as `c:Badge`, a `ContentControl` with Cosmo's control theme (`src/Aioros.Cosmo/Display/Badge.axaml`).

| AC | Criterion |
| --- | --- |
| BADGE-01 | Given the `badge-variants` fixture in the light and the dark theme on the web, when Chromium computes each badge, then its box (x, y, width and height, 22 px high), its background, color, border color, corner radius (fully rounded) and its text's size and weight (12 px, 500) are those of shadcn/ui's badge of that variant (default, `secondary`, `destructive`, `outline`, `ghost`, `link`); in the `badge-icons` fixture (an icon with a text, and count badges) every badge's vertical position and height are shadcn/ui's within 0.5 px, and the horizontal position and width of the badge with an icon too (the count badges are set in shadcn's monospace font, which Aioros cannot write yet: see the decisions). |
| BADGE-02 | Given a `c:Badge` of each variant in each variant of the theme on the desktop, when it is shown, then its resolved background, foreground and border brush are the colors Chromium computes for shadcn/ui's badge (`badge-variants`), within 1/255 per channel, its padding is 8 px by 2 px inside a 1 px border and its corner radius fully rounded. |
| BADGE-03 | Given a `c:Badge` holding a `StackPanel` of a 12 px icon and a text, when it is shown on the desktop, then the panel is horizontal with a 4 px gap, as shadcn's `gap-1` and `[&>svg]:size-3`. |
| BADGE-04 | Given the `badge-links` fixture in each theme on the desktop (a `HyperlinkButton` with the `CosmoBadgeLink` theme in each variant: none, `secondary`, `destructive`, `outline`, `ghost`, `link`, as shadcn/ui's `<Badge asChild><a href>`), when each is shown, hovered and given the keyboard focus, then its size is shadcn/ui's within 1.5 px, 8 px after the previous one (Avalonia rounds each width up to a whole pixel), with the badge's colors at rest, under the pointer its background and text are shadcn/ui's `[a&]:hover` look (`--primary`, `--secondary` and `--destructive` at 90%, `--accent` with `--accent-foreground` for `outline` and `ghost`, an underline for `link`), and with the focus its border is `--ring` and its ring shadcn/ui's 3 px `--ring` at 50% (`--destructive` at 20%, 40% dark, for `destructive`). |
| BADGE-05 | Given the `badge-links` fixture in each theme on the web, when it is served and Chromium computes each badge at rest, under the pointer and with a visible keyboard focus, then each is an `<a href>` with shadcn/ui's box within 1 px, and its background, text color, border, text decoration and ring are shadcn/ui's in each state, as BADGE-04 states for the desktop. |
