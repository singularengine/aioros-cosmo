# Date Picker

shadcn/ui's `date-picker` (a `Popover` whose trigger is an outline button with the calendar icon and the date, and
whose content is a `Calendar`) and its `input` variant (an input with a ghost calendar button inside) as Avalonia's
`CalendarDatePicker` with Cosmo's theme: the button variant shows the icon and the formatted date (`MMMM d, yyyy`; the
placeholder `Pick a date` in the muted foreground) and opens a popover 4 px below it with Cosmo's calendar; the `input`
class is an input whose text can be typed, with a 24 px ghost button opening the popover at its end. `SelectedDate`
binds two way.
