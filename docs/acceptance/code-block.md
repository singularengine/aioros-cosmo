# Code Block

shadcn/ui's `code-block` from the radix base (`apps/v4/registry/bases/radix/ui/code-block.tsx`) in the radix-rhea style,
on Cosmo's new-york-v4 tokens (decided with the user on 2026-10-19): an 18 px rounded block of `--muted` with a 1 px ring
of `--foreground` at 5% (10% in the dark), its header of a 14 px medium title and its actions (24 px round ghost buttons),
its code in 14 px Geist Mono on 22.75 px lines, scrolling sideways or wrapped, its lines numbered, highlighted, added or
removed; the `destructive` variant and the `sm` size. Cosmo's `c:CodeBlock` (a `ContentControl`: `Title`, `Actions`,
`Footer`; `destructive`, `sm`), `c:CodeBlockContent` (a `ContentControl`: `LineNumbers`, `StartLine`, `Wrap`) and
`c:CodeBlockLine` (a `ContentControl`: `Number`; `highlighted`, `added`, `removed`). The code is highlighted when the XAML
is written, by the shiki shadcn/ui uses (github-light and github-dark): each token is a `Run` on one of Cosmo's code
brushes, so the desktop and the web draw the same XAML and the browser runs no highlighter.
