# Command

shadcn/ui's `command` (cmdk 1.1.1) as `c:Command` (a sealed `ItemsControl`: its input, `Placeholder`, `Text` and
`SelectedValue` two way, `Empty`, `ShouldFilter`, `IsLoop`, `Filter`, cmdk's `command-score` in `CommandScore`),
`c:CommandGroup` (a `HeaderedItemsControl` of `c:CommandItem`s, `ItemsSource` and `ItemTemplate`), `c:CommandItem` (a
sealed `Button`: `Value`, `Keywords`, `Shortcut`, its `Command` run when chosen), `c:CommandSeparator`, and
`c:CommandDialog` (the command in a dialog, `IsOpen` two way, toggled by its `Gesture`).
