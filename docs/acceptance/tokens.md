# Design tokens

shadcn/ui's design tokens as Avalonia resources (`src/Aioros.Cosmo/Theming`), generated by `tools/shadcn/tokens.mjs`
from the pinned registry (`tools/shadcn/registry`). The conversion and every value are in [../tokens.md](../tokens.md).

| AC | Criterion |
| --- | --- |
| TOKENS-01 | Given each of the twelve color dictionaries (the base colors neutral, zinc, slate, stone and gray from `public/r/colors/*.json`'s `cssVarsV4`, and red, rose, orange, green, blue, yellow and violet from `baseColorsOKLCH`) in its light and dark variant, when it is loaded, then each of the 31 tokens (`background` … `sidebar-ring`) is a `Cosmo{Token}Color` and a `Cosmo{Token}Brush` whose color is the token's oklch value converted to sRGB (CSS Color 4's OKLab matrices and transfer function, each channel clipped to 0..1 and rounded to 8 bits) with its alpha (`oklch(1 0 0 / 10%)` is `#1AFFFFFF`), exactly. |
| TOKENS-02 | Given the 744 token values of the twelve color themes in both variants, when the converter of TOKENS-01 converts them, then each equals the RGBA Chromium's 2D canvas paints for the same CSS value (`tools/shadcn/out/metrics.json`) within 1/255 per channel, so out-of-gamut colors (`--destructive: oklch(0.577 0.245 27.325)`, `#E7000B`) are clipped as Chromium shows them on an sRGB display. |
| TOKENS-03 | Given the six radius dictionaries (`--radius` 0, 0.3, 0.5, 0.625, 0.75 and 1 rem, `CosmoRadius` None, Small, Medium, Default, Large and ExtraLarge), when one is loaded, then `CosmoRadius` is the radius in px (16 px per rem) and `CosmoRadiusSm`, `Md`, `Lg`, `Xl`, `2Xl`, `3Xl` and `4Xl` are corner radii of 0.6, 0.8, 1, 1.4, 1.8, 2.2 and 2.6 times it, as the registry's CSS updater writes `--radius-sm` … `--radius-4xl` (the default: 6, 8, 10, 14 px for sm, md, lg, xl). |
| TOKENS-04 | Given a color dictionary in each variant, when it is loaded, then the component brushes carry the token colors with the opacities shadcn's classes apply (`CosmoButtonPrimaryHoverBrush` is `--primary` at 90%; `CosmoButtonDestructiveBrush` `--destructive` at 100% in light and 60% in dark; `CosmoButtonOutlineBrush` `--background` in light and `--input` at 30% in dark; `CosmoButtonOutlineHoverBrush` `--accent` and `--input` at 50%; `CosmoButtonSecondaryHoverBrush` `--secondary` at 80%; `CosmoButtonGhostHoverBrush` `--accent` and `--accent` at 50%; `CosmoFocusRingBrush` `--ring` at 50%), and the shadows are shadcn's (`CosmoShadowXs` `0 1 2 0 #0D000000`, `CosmoShadowSm` `0 1 3 0 #1A000000, 0 1 2 -1 #1A000000`, `CosmoFocusRingShadow` a 3 px spread of `--ring` at 50%). |
| TOKENS-05 | Given the twelve color dictionaries, when their keys are listed per variant, then all 24 hold the same set of keys, so switching a color theme never leaves a resource of the previous one in effect, and a key missing from one fails with its name. |
