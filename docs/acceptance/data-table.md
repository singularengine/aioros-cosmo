# Data Table

shadcn/ui's data table guide (TanStack Table 9.0.0 over its `Table`) as Avalonia's `TableView` in Cosmo's table themes
with its columns in XAML (header controls: a three-state `CheckBox`, a ghost sort `Button`; cell templates), and
`DataTableSource<T>` in the view model: the rows filtered (`FilterText`, `FilterColumn`, TanStack's `includesString`),
sorted (`SortCommand`, alphanumeric and case-insensitive, ascending then descending), paged (`PageSize`, `PageIndex`,
`PreviousPageCommand`, `NextPageCommand`) into `Rows`, the selection on the rows (`IDataTableRow.IsSelected`,
`SelectedCount`, `AllPageRowsSelected`) and the columns' visibility (`DataTableColumn.IsVisible`, two way);
`c:DataTable.SelectsRows` gives the selected rows the `selected` look.
