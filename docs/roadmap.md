# Roadmap

What Aioros.Cosmo covers today and what comes next. It is in public preview, so its APIs can still change.

## What exists today

- [x] Every component in shadcn/ui's registry, compared with its own render
- [x] Twelve color themes in light and dark, and the radius scale
- [x] Charts through Aioros.Pictor
- [x] Chat components, including Markdown rendering
- [x] Blocks: dashboards, sidebars and sign-in pages
- [x] A project template and preview packages on NuGet

The list, row by row, is in [Coverage](coverage.md).

## What comes next

- A bound empty text on the file input that follows its value.
- Whatever real apps ask for.
